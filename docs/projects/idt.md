# Information Distinction Theory

## One-line Summary

Information Distinction Theory studies how structural distinctions may generate effective informational constraints and geometrical organization.

## Central Intuition

Reality can be approached through the distinctions that make transformations possible, constrained, or inadmissible.

## Structural Problem

Many research fields use related concepts such as information, coherence, geometry, complexity, and constraints, but these ideas are often described in incompatible languages.

## Key Concepts

| Concept       | Meaning                                                   | Status |
| ------------- | --------------------------------------------------------- | ------ |
| Distinction   | A structural difference that makes information meaningful | Draft  |
| Coherence     | Compatibility across descriptions or transformations      | Draft  |
| Degradation   | Cost associated with loss of structural coherence         | Draft  |
| Admissibility | The set of transformations a system can sustain           | Draft  |

## Formal Structure

Initial roadmap:

```text
misalignment → coherence → degradation → constraint → geometry
```

## Current Stage

Conceptual roadmap with early mathematical formulation.
